## Replacement Instructions

### Sigil (`sigil-three-headed-red.svg`)
- Required: SVG with `viewBox="0 0 200 200"`, transparent background, red (#a31313) emblem
- Max size: 100 KB
- Drop in the same path, rebuild

### Favicon (`favicon-dragonpit.svg`)
- Required: SVG, square viewBox, works at 16×16 and 32×32
- Also provide a PNG fallback if needed (`favicon-dragonpit.png`, 32×32)
